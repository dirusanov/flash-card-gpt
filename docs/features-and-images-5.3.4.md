# Возможности и картинки — 5.3.4

Изменения от 4 октября 2026 года. 5 октября версия 5.3.4 загружена в Chrome Web Store
и отправлена на проверку с автоматической публикацией после одобрения Google.
Серверные изменения развёрнуты на VPS.

## Что видит пользователь

- На экране создания, с ключом и без него, есть **All features**: перевод,
  примеры, грамматика, картинки, озвучка, редактирование и колоды, повторение,
  экспорт в Anki, синхронизация и расширенные настройки AI.
- У каждой функции объяснены условия и есть переход к карточкам, настройкам
  или аккаунту. Возможности не скрываются до ввода API-ключа.
- В бесплатном режиме виден **Image** и состояние доступности. Старый сервер
  показывается как режим без картинок с переходом к настройке своего ключа.
- При доступной бесплатной генерации картинки запрашиваются по выбору
  пользователя. Выбор сохраняется между открытиями панели.
- Готовая карточка сразу показывает ответ и картинку. Первое повторение
  после сохранения начинается с вопроса.
- В режиме своего ключа явно сказано: **Smart** пропускает абстрактные слова,
  **Every card** запрашивает картинку каждый раз.
- Сбой картинки не теряет текст и озвучку. В предпросмотре появляется
  сообщение, а кнопка сохранения остаётся доступной.

## Серверная часть

Изменения в `backend/cards_sync_service`: опциональный `include_image`, поле
возможностей `images_available`, генерация постоянного JPEG, сохранение
картинки и её статуса в существующем результате запроса. Новая миграция не нужна.
Изображения включаются отдельно через `TRIAL_IMAGES_ENABLED=true`; по умолчанию
они выключены. Для выкладки нужны обновлённый сервис, доступ к модели,
проверенные лимиты расходов и таймаут прокси не менее 150 секунд.

Старый сервер и старые клиенты поддерживаются. Сохранены отпечатки старых
запросов: повтор после обновления сервера не должен расходовать новую попытку.
Ответ не содержит временную ссылку на изображение; картинка сохраняется с
карточкой и не истекает.

Параметры Images API сверены с [официальной документацией OpenAI](https://developers.openai.com/api/reference/python/resources/images/methods/generate).

## Проверка

- TypeScript: `npx tsc --noEmit`.
- Клиент: `node utils/test-quick-start/run.js` — совместимость старого сервера,
  состояние возможностей, запрос картинки, сохранение и восстановление черновика,
  отказ от непригодного/слишком большого изображения, сообщения о сбое,
  отмена и повтор без изменения идентификатора запроса.
- Сервер: 55 тестов прошли на VPS в production Docker-образе с Python 3.13
  и отдельной временной базой Postgres, включая все интеграционные тесты.
  Устаревший тест грамматического форматирования исправлен; Docker-сборка
  теперь устанавливает версии зависимостей из poetry.lock.
- Реальный production-бандл вручную проверен в Chrome в рамке 360×640 с
  тестовыми ответами: бесплатный режим, обзор функций, переход к настройке
  картинок, изображение на обороте, восстановление после перезагрузки,
  сообщение при сбое и сохранение текстовой карточки, начало повторения с
  вопроса, собственный ключ и подсказка Smart. Использован тестовый логотип
  вместо AI-картинки; реальных платных AI-запросов не было.
- Проверка content script на 20 вкладках прошла: в простое нет таймеров,
  сканирования DOM, сетевых запросов, сообщений или наблюдателей. Эти изменения
  работают в интерфейсе расширения; новая генерация выполняется по нажатию.
- Production-сборка и проверка CRC ZIP прошли. Пакет: `build-5.3.4.zip`.

## Статус выпуска 5 октября

Chrome Web Store: версия 5.3.4 ожидает рассмотрения, автоматическая публикация
после проверки включена. Обновлены английское и русское описания и ссылка поддержки.

Сервис карточек обновлён на VPS; nginx допускает ожидание ответа 180 секунд.
Сайт пересобран и перезапущен. Сервисы авторизации и заметок уже соответствовали
локальным версиям, миграции находятся на head.

Бесплатные картинки остаются выключены (`TRIAL_IMAGES_ENABLED=false`);
изменения поддерживают этот режим и картинки с собственным ключом.
Платные запросы к генерации изображений в production не выполнялись.
